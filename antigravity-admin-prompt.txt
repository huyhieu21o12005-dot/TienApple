STEP 1: DATABASE (write supabase/schema.sql, I will run it in the Supabase SQL editor)
Table products, matching the current products.json fields:
- id text primary key (slug, e.g. "ip16-pro", never edited after creation)
- name text not null, kind text not null check in ('phone','accessory'), category text (e.g. 'case', 'audio')
- brand text, brand_name text, condition text check in ('new','like_new','used'), condition_label text, badge text
- price bigint not null check (price >= 0), old_price bigint check (old_price >= 0)
- colors jsonb default '[]' (array of {name, hex}), default_color text, storages jsonb default '[]' (array of strings)
- chip text, camera text, battery text, screen text, description text
- rating numeric default 5, review_count int default 0
- image_url text, stock int default 0, is_visible boolean default true
- sort_order int default 0, created_at timestamptz default now(), updated_at timestamptz default now() (auto-updated by a trigger)
RLS:
- Enable RLS. Public (anon) can SELECT only rows where is_visible = true.
- Only authenticated users can SELECT all rows, INSERT, UPDATE, DELETE.
Storage: public-read bucket "product-images"; only authenticated users can upload/update/delete. Limit file size to 5 MB, images only.
